Add semantic conventions for Ollama.

This change adds comprehensive semantic conventions for the Ollama platform,
including:

- New attribute group in `model/ollama/registry.yaml` with Ollama-specific attributes:
  - Request attributes: `ollama.request.model`, `ollama.request.base_url`,
    `ollama.request.stream`, `ollama.request.temperature`, `ollama.request.top_p`,
    `ollama.request.top_k`, `ollama.request.max_tokens`, `ollama.request.stop`,
    `ollama.request.repeat_penalty`, `ollama.request.seed`, `ollama.request.num_predict`,
    `ollama.request.num_ctx`, `ollama.request.num_batch`, `ollama.request.num_gpu`,
    `ollama.request.main_gpu`, `ollama.request.low_vram`, `ollama.request.f16_kv`
  - Response attributes: `ollama.response.model`, `ollama.response.total_duration`,
    `ollama.response.load_duration`, `ollama.response.prompt_eval_count`,
    `ollama.response.eval_count`

- New documentation in `docs/gen-ai/ollama.md` with:
  - Overview of Ollama semantic conventions
  - Span definitions for client operations
  - Detailed attribute descriptions
  - Trace examples for chat completion and streaming

- Updated `docs/gen-ai/README.md` to include Ollama in the list of
  technology-specific semantic conventions.

- New test file `reference/tests/test_ollama.py` with tests for:
  - All Ollama-specific attribute definitions
  - Expected values and examples
